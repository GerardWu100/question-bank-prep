# Chapter 3 Equity Valuation

## Case Maple Leaf Utilities
Maple Leaf Utilities pays a steady dividend. An analyst values the stock with the Gordon growth model.

### Exhibit 1 Inputs

| Input | Value |
|---|---|
| Next year's dividend $D_1$ | \$2.00 |
| Required return $r$ | 8% |
| Dividend growth $g$ | 3% |

### Question 1
What is the intrinsic value per share?

#### Choices
A. \$25.00
B. \$40.00
C. \$66.67

#### Answer
B

#### Solution
$V_0 = D_1 / (r - g) = 2.00 / (0.08 - 0.03) = 40.00$.

### Question 2
If growth rises to 4% and nothing else changes, the value:

#### Choices
A. falls.
B. stays the same.
C. rises.

#### Answer
C

#### Solution
$V_0 = 2.00 / (0.08 - 0.04) = 50.00$, which is higher than \$40.00.
